# idea2app ESLint rules for TSX

Shared TypeScript + JSX ESLint rules for idea2app projects.

## Upstream rules

1. [`eslint-idea2app-js`][1] - idea2app JavaScript baseline.
2. [`typescript-eslint`][2] - TypeScript recommended rules.
3. [`eslint-plugin-react`][3] - React JSX rules.
4. [`eslint-plugin-jsx-a11y`][4] - JSX accessibility rules.
5. [`@stylistic/eslint-plugin`][5] - stylistic formatting rules.

[1]: https://npm.im/eslint-idea2app-js
[2]: https://typescript-eslint.io/users/configs
[3]: https://github.com/jsx-eslint/eslint-plugin-react
[4]: https://github.com/jsx-eslint/eslint-plugin-jsx-a11y
[5]: https://eslint.style/packages/plus
