# idea2app ESLint rules for TSX

Shared TypeScript + JSX ESLint rules for idea2app projects.

## Included rule areas

- ESLint recommended JavaScript baseline
- TypeScript recommended rules from `typescript-eslint`
- JSX accessibility baseline from `eslint-plugin-jsx-a11y`
- React JSX consistency rules (`self-closing-comp`, `jsx-sort-props`, etc.)
- Import ordering via `eslint-plugin-simple-import-sort`
- Spelling checks via `@cspell/eslint-plugin`
- Stylistic statement padding via `@stylistic/eslint-plugin`
