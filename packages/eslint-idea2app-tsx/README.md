# idea2app ESLint rules for TSX

Shared TypeScript + JSX ESLint rules for idea2app projects.

## Upstream rules

1. [`@eslint/js`][1] - ESLint recommended baseline.
2. [`typescript-eslint`][2] - TypeScript recommended rules.
3. [`eslint-plugin-react`][3] - React JSX rules.
4. [`eslint-plugin-jsx-a11y`][4] - JSX accessibility rules.
5. [`eslint-plugin-simple-import-sort`][5] - import sorting rules.
6. [`@stylistic/eslint-plugin`][6] - stylistic formatting rules.
7. [`@cspell/eslint-plugin`][7] - spellcheck rules.
8. [`eslint-config-prettier`][8] - disables Prettier-conflicting rules.
