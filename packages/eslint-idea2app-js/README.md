# idea2app ESLint rules for JavaScript

Shared JavaScript ESLint rules for idea2app projects.

## Upstream rules

1. [`@eslint/js`][1] - ESLint recommended baseline.
2. [`eslint-plugin-simple-import-sort`][2] - import sorting rules.
3. [`@cspell/eslint-plugin`][3] - spellcheck rules.
4. [`eslint-config-prettier`][4] - disables Prettier-conflicting rules.

[1]: https://eslint.org/docs/latest/
[2]: https://github.com/lydell/eslint-plugin-simple-import-sort
[3]: https://github.com/streetsidesoftware/cspell/tree/main/packages/cspell-eslint-plugin
[4]: https://github.com/prettier/eslint-config-prettier
